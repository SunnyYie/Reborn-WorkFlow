# PCO 中文歌词下载

## 下载规则

按歌曲独立执行以下优先级：

1. 有现成中文歌词：下载中文歌词，或将 API 的中文歌词字段原样保存为 UTF-8 TXT。
2. 没有现成中文歌词，但有简谱：仅下载原始简谱附件。
3. 中文歌词和简谱都没有：不触发该歌的文档下载，不创建空文档或占位文件；回复哪些歌未找到。完整 workflow 已明确授权的对应 Key MP3 不受文档缺失影响，由定调模块单独处理。

禁止人工转录、OCR、翻译、补写或凭记忆生成歌词。图片简谱保持原文件，不转成歌词文本。英文歌词不能代替中文歌词；普通五线谱或和弦谱不能未经核实当作简谱。不要将前一轮已有的人工转录文件当作 PCO 原始歌词。

只处理用户点名的歌曲。本 skill 不额外下载英文版、音频、视频或其他附件；完整 workflow 明确要求的已试听确认 Key 对应 MP3，由定调模块与本下载流程统一交付，不是本 skill 自动扩大范围。不要修改 PCO 歌曲、编曲、排班或权限；不安装或修改全局配置。

## 准备与凭据

- 可使用已配置的官方 MCP、`pco` CLI 或 Planning Center API。只使用当前实际可用的工具，不假设 MCP 必然暴露附件下载。
- `pco` 已配置时，先用 `pco me` 确认账号；需要用户授权的钥匙串访问或网络操作按环境要求申请。
- 缺少凭据时，请用户在本机执行 `pco init`。不要索要聊天中的 Secret。
- CLI 凭据通常来自 macOS 钥匙串：service 为 `pco-cli`，account 为 `client_id` 和 `client_secret`。API 必须直接调用时，在进程内读取并使用，不打印凭据，不写入 skill、源码、日志或下载文件。
- 遇到 401/403 停止该请求并说明认证或权限问题，不误报为“没有歌词”。暂时性网络超时最多重试一次；仍失败则报告“未能验证”，不要改断言或绕过权限。

## 歌曲与来源查找

1. 按用户歌名搜索，读取真实 ID，不复用示例 ID：

   ```sh
   pco songs search --query "<歌名>" --json
   pco songs arrangements <song-id> --json
   ```

2. 中文名可能包含在中英双语标题中。检查所有搜索结果；多个合理候选且版本无法判断时，请用户确认，不猜选。区分“未找到歌曲”和“歌曲存在但没有可下载内容”。
3. 检查该歌曲的现役编曲、歌曲级附件和编曲级附件；必要时再看各 Key 的附件。分页应读取完整，不能用空的第一页或单个空编曲断言缺失。
4. 优先找中文 `lyrics` 字段和现有中文歌词附件（如 TXT、DOCX、PDF）。`lyrics_enabled=true` 不代表实际有歌词；`null`、空串和纯英文歌词均不算中文歌词。
5. 判断中文歌词附件需结合文件名、类型和可取得的文本或预览。明显的“中文歌词”附件可优先下载；含混标题先检查元数据或预览，不批量下载附件碰运气。不对图片进行 OCR 或转录。
6. 仅当未找到中文歌词时检查简谱。简谱以附件名称、类型和必要的谱面预览确认；有多个内容等价的调性版本时，优先用户指定调性，否则保留文件名并说明版本。无法消除的版本歧义请用户确认。
7. 不主动使用归档编曲替代现役版本；若只在归档版本发现内容，说明版本并确认后下载。

## API 与下载细节

CLI 没有暴露需要的字段时，可在现有授权下使用官方 API。先查响应的 `links`，不要臆造附件地址：

```text
GET /services/v2/songs/{song_id}
GET /services/v2/songs/{song_id}/arrangements
GET /services/v2/songs/{song_id}/arrangements/{arrangement_id}
GET /services/v2/songs/{song_id}/attachments
GET /services/v2/songs/{song_id}/arrangements/{arrangement_id}/attachments
```

- 编曲详情的 `attributes.lyrics` 可能为 `null`。仅当实际包含中文歌词时保存 TXT，保留原文字词及段落，不转换“你/祢”或繁简体，不补演唱顺序。
- 附件列表提供 `downloadable`、`filename`、`content_type`、`filetype` 等信息。不可下载的附件直接报告限制，不绕过访问控制。
- PCO 附件下载动作：

  ```text
  POST /services/v2/attachments/{attachment_id}/open
  ```

  从返回的 `data.attributes.attachment_url` 获取下载地址，再下载文件。GET 到 `/open` 只返回动作说明，不是实际文件。该 POST 是生成下载链接的必要动作，可能留下下载活动记录，不等于修改歌曲内容。
- Basic Auth 仅用于官方 API。访问签名下载地址或跨域重定向时不转发 Authorization，不在回复或交付文件中暴露签名 URL。
- 验证响应格式、文件签名和非空内容，避免把 HTML 登录页或 JSON 错误保存为 PDF/DOCX。失败后不宣称下载完成。

## 本地交付

- 优先使用用户指定的保存目录；没有指定时使用当前任务允许的交付目录（如 `outputs/`）。中间元数据放工作目录，不作为用户交付。
- 保留附件原格式及有意义的中文文件名；字段导出可命名 `<歌名>-中文歌词.txt`。已有同名文件时比较来源或使用不覆盖的文件名，不覆盖用户文件。
- 无中文歌词而下载简谱时，明确标记“仅简谱”，不要提供伪装成歌词的 TXT。
- 回复按歌曲列出实际可用的本地文件链接。简短说明哪些是歌词、哪些是简谱，另列未找到或验证失败的歌曲及原因；没有缺失就不加缺失段落。
- 对“没有”的结论，必须区分：未找到歌曲、已检查来源但无中文歌词/简谱、权限受限、网络失败、版本待确认。

## 决策验收

- 中文歌词 + 简谱：只下载中文歌词。
- 空 `lyrics` + 中文歌词 DOCX + 简谱：只下载中文歌词 DOCX。
- 空 `lyrics` + 英文歌词 PDF + 中文简谱：只下载中文简谱，不转录。
- 空 `lyrics` + 无简谱：不下载，报告该歌缺失。
- 401/403 或网络失败：报告无法验证，不声称内容不存在。
- 全程不变更歌曲内容，不把密钥写入任何文件。
