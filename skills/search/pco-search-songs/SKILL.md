# PCO 按主题与音乐特征选曲

## 目标与边界

从用户自己的 PCO 歌曲库查找合适的歌曲，结合实际编曲 BPM、拍号、歌词和可用说明给出候选及理由。没有明确要求外部推荐时，不用库外歌曲冒充库内结果。

搜索只读；不下载附件或音频，不生成歌词，不创建或修改计划、歌曲、编曲及排班。用户另行要求下载时，再使用下载 skill，遵循“中文歌词优先，其次简谱，两者都没有则跳过”，不人工转录或 OCR。

## 1. 理解选曲条件

- 提取主题（如亲近神、呼求、悔改、感恩）、速度、氛围、语言、聚会环节和数量。
- 条件清楚时直接查询，不为可选信息反复提问。未明确语言时，不因中文对话排除英文歌，但要标明中文资源是否已确认。
- 区分“分别覆盖几个主题”和“每首同时满足多个主题”。结果中说明匹配程度，不把“与神的关系”泛化成所有敬拜歌曲。
- 用户未给数字时，可将约 50–75 BPM 的常见 4/4 编曲作为慢速初筛参考，明确这只是本次筛选口径，不是固定音乐定义或硬性阈值。

## 2. 检索真实歌曲库

用户有具体歌名或希望复用已有歌单时，**先读 [历史歌单 RAG](../../../rag/SKILL.md)**，查本地结构及歌词。精确命中且用户选择版本后可直接组装，不为核验旧资料再次下载/分析；近似命中只是候选。历史库与 PCO 当前目录分开标识，不给历史资料伪造 PCO ID。主题查找可用词句向量召回再阅读真实歌词，但它不是深度语义模型；未命中或用户明确查当前 PCO 时继续下列查询。

可使用当前可用的官方 MCP 或已认证的 `pco` CLI；不假设某个 MCP 工具已加载。

```sh
pco me
pco songs search --json
pco songs search --query "<歌名或标题关键词>" --json
pco songs arrangements <song-id> --json
```

- 凭据来自现有安全配置；缺少时提示用户本机运行 `pco init`，不索要聊天中的 Secret、不输出钥匙串内容。
- 歌名搜索通常是标题搜索，不是歌词语义搜索。必要时完整读取歌曲列表和分页，从中选出主题候选，再检查编曲；只用“呼求”等关键词搜标题可能漏掉主题相关歌曲。
- 默认优先非隐藏歌曲和非归档编曲。若纳入隐藏或归档内容，单独标明。
- 使用响应里的真实歌曲及编曲 ID；双语歌名应保留用于辨识。遇到同名或版本差异，不擅自合并。
- 先粗筛再查候选的编曲，按需扩大；不要固定只查历史某 18 首或将历史 ID 当作永久目录。
- 若并行查询，使用少量并发并尊重实际限流。暂时性超时最多重试一次；401/403 停止并报告权限问题，429 按服务端提示退避且不无限重试。保留失败候选，不把请求失败解释为无结果。

## 3. 按编曲核验

对候选记录歌曲名、song ID、编曲名及 ID、BPM、拍号、歌词可用性、主题证据和缺失信息。

### 速度

- 使用实际编曲的 `bpm` 和 `meter`；`null` 或空值写“未填写”，不得凭熟悉程度补成 PCO 数据。
- 同一首歌不同编曲可以有不同速度，分别标明，例如“52 BPM / 65 BPM，两种编曲”，不能求平均冒充实际版本。
- 3/4、6/8 和 4/4 的 BPM 不能直接按数字比较快慢；拍点单位、半拍/双倍速度不明时说明不确定，不强行换算。
- BPM 只说明速度，不能证明柔和、音量、配器、音域或会众熟悉程度。

### 主题

- 优先检查当前查询取得的 `lyrics`，读出主题后用简短概括说明，不整段展示歌词。
- `lyrics_enabled=true` 不代表有内容；空字段不代表歌曲无主题或没有中文附件。
- 有实际歌词支持的主题、仅凭通行版本认识的判断、仅凭歌名的候选必须分开标记。标题只能帮助初筛。
- 当前编曲没有歌词时，优先选择已有证据更充分的候选；确需核验附件时先说明该步超出纯元数据搜索，不擅自触发下载。
- 历史附件核验可作参考，但明确是历史观察；用户要求当前确认时重新验证。

### 氛围

- 未试听则明确“未试听，柔和程度属编配建议/待确认”，不得声称已听过 PCO 音频。
- 查到明确的原声、钢琴或动态说明可作为辅助证据，不把歌名或低 BPM 当作实际配器证明。
- 留意桥段和后半段可能增强动态。建议轻配器不等于原编曲已被证实柔和。
- 不擅自改变调性或速度。可提出演绎建议，但与库内事实分开。

## 4. 组织推荐

通常返回少量高匹配候选，优先顺序为：主题匹配、速度条件、氛围证据、可用版本。不要为凑数量加入明显不符歌曲。

推荐表使用以下信息中对本次任务有用的列：

| 歌曲 | 编曲 / BPM / 拍号 | 主题匹配 | 已核验与待确认 |
| --- | --- | --- | --- |

- 先交代搜索范围：库内候选筛选还是完整编曲扫描。查过歌曲目录不等于查过全库编曲；不得称“全库最慢/最合适”而没有相应证据。
- 简洁标注歌词支持、仅版本常识判断、BPM 未填写、中文资源未确认等差异。
- 用户需要时给出几首歌的主题推进顺序，并标明是建议，不是已经修改 PCO 计划。
- 没有严格匹配时，坦率说明，分别列接近条件和未核验项，不编造 BPM、歌词内容或下载可用性。
- 结尾说明必要的验证缺口；没有执行下载或写入就不要暗示已执行。

## 决策验收

- 67 BPM 且歌词明确表达认识神：主题和速度有证据；未试听仍不能断言柔和。
- 66 BPM 但歌词为空：速度已核验，主题待核验，不仅凭歌名列为完全匹配。
- 歌词吻合但 BPM 缺失：可作待核实备选，不虚填速度。
- 90 BPM 且主题吻合：说明偏离此次慢速口径，不静默当作慢歌。
- 搜索推荐不自动触发附件下载、人工转录、OCR 或任何 PCO 内容修改。
